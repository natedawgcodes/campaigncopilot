# Intake: fields to collect before building a script

Gather these before writing. Pull what you can from the user's request, ask for
the essentials that are missing, and use clearly labeled placeholders for the
rest so the user can fill them in. Note next to each field below what it drives in
the script.

## Where these fields come from

If a `campaigns/<name>.md` profile exists, reuse the shared fields from it and do not
re-ask. Run the `campaign-setup` skill to create one if there is none.

- From the profile: candidate name, office, district or jurisdiction, party,
  opponent(s), top issues, default tone, and key dates (election date and early-vote
  window). The profile's notes section may also hold do-not-say language, a slogan,
  or endorsements.
- Ask per task (not stored in the profile): the contact method (door, phone, or
  SMS), the purpose (voter ID, persuasion, GOTV, volunteer recruitment, or ballot
  chase), the voter segment for this script, operational local specifics the profile
  does not hold (polling place or drop-box info, registration or ballot-request
  deadlines), do-not-call status, and SMS opt-in source.

The field notes below still apply; the profile simply pre-fills the shared ones.

## Campaign basics

- **Candidate name.** Used throughout, and in the opening and closing.
- **Office.** The seat being sought (for example, State House District 12, Mayor,
  School Board). Sets formality and which issues land.
- **District or jurisdiction.** Where these voters live. Drives local specifics
  and which races and issues are relevant.
- **Party (optional).** Helps set tone and which contrast is fair game. Leave out
  for nonpartisan or cross-partisan outreach.
- **Opponent or opponents.** Needed for persuasion contrast and rapid response.
  Used carefully and factually, never as the lead.

## Message inputs

- **Top 3 issues.** The campaign's priority issues, in order. These key the
  persuasion points directly, so phrase them the way the campaign talks about
  them, not as abstract topics.
- **Voter segment for this script.** Who this script targets (for example,
  base Democrats, undecided independents, sporadic voters, vote-by-mail
  households, voters under 35). Drives the target audience section and tone.
- **Tone.** One of: professional, populist, or neighborly.
  - *Professional:* measured, informed, credible.
  - *Populist:* plain-spoken, us-versus-the-status-quo energy.
  - *Neighborly:* warm, local, first-name, "your neighbor" framing.

## Logistics

- **Contact method.** Door canvass, phone bank, or SMS. Sets length and format.
- **Purpose.** Voter ID, persuasion, GOTV, volunteer recruitment, or ballot
  chase. Sets the question flow and the closing ask.
- **Local specifics.** Election date, early-vote start and end dates, polling
  place or drop-box info, and registration or ballot-request deadlines. GOTV and
  ballot chase scripts depend on these.

## Compliance notes

Captured as awareness inputs, not legal advice. They drive the reminder lines in
the script.

- **Do-not-call status.** Confirm the calling list respects do-not-call flags and
  that the program honors stop requests. Relevant to phone scripts.
- **SMS opt-in source.** Where these numbers opted in (for example, a sign-up
  form, an event, a petition). Relevant to TCPA and opt-in awareness on SMS
  scripts.

The user is responsible for confirming the legal requirements for their own
jurisdiction. This intake does not provide legal advice.
