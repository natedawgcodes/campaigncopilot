# Profile template: campaigns/<name>.md

Write the profile in this exact format. Keep the field labels as written so the
other skills can read them reliably, and keep the layout clean so the user can
hand-edit it. Fill every field you have, and leave a clear placeholder in brackets
for anything skipped.

```
# Campaign profile: [Candidate Name]

<!-- Campaign-internal file. Do not commit to a public repository. -->

## Candidate and race
- Candidate name: [Full name]
- Office sought: [Office, for example State House District 14]
- District or jurisdiction: [Where these voters live]
- Party: [Party, or "nonpartisan"]

## The contest
- Opponent(s): [Name(s), or "TBD"]
- Top issues:
  1. [Issue one]
  2. [Issue two]
  3. [Issue three]

## Voice
- Default tone: [professional, populist, or neighborly]

## Key dates
- Election date: [YYYY-MM-DD]
- Early-vote window: [YYYY-MM-DD to YYYY-MM-DD, or "none"]

## Notes
[Free text. Do-not-say language, slogan, values, endorsements, strategy notes,
anything the skills should know. Leave blank if there is nothing yet.]
```

Name the file from the candidate: lowercase and hyphenated, so "Jane Miller"
becomes `campaigns/jane-miller.md`. After writing, confirm the path back to the
user.
