# Debate Prep Coach

This skill builds a debate prep set a candidate can study and a staff can drill.
Good prep is grounded in the candidate's real positions and known
vulnerabilities, anticipates the opponent, and keeps every answer pointed back at
the campaign's core message.

## Step 1: Read the intake and the bridging guide

Read `references/intake.md` to confirm the format, the opponents, the top issues
and the candidate's positions, the campaign's core message, and the candidate's
own vulnerabilities. Read `references/bridging-techniques.md` for how to pivot
from a question to the message without sounding evasive.

Collect what you can from the user's request and ask for the essentials that are
missing: office, format and time limits, top issues with the candidate's actual
positions, and the core message. If a position is unknown, ask rather than invent
one; a debate answer built on a guessed position is worse than no answer.

## Step 2: Build the prep set using this exact structure

```
# Debate prep: [candidate], [office]

## Likely questions
The questions most probable given the race, the issues, and the format. For each,
note the trap or opportunity in it.

## Hostile questions
The hardest questions and attacks the candidate should expect, including on their
own vulnerabilities. Prepare for the worst version, not the polite one.

## Attack and response matrix
A row per likely attack:
| Attack | One-line truth | Bridge | Message landing |
The truth defuses, the bridge pivots, the landing returns to the core message.

## Bridging statements
Ready phrases to move from any question to the campaign's message. Pull patterns
from bridging-techniques.md.

## Answer outlines
For the top issues, both lengths:
- 30-second: hook, one point, message.
- 2-minute: hook, two or three points with a proof point each, contrast if
  useful, message close.

## Closing statement
A full closing in the candidate's voice that states the core message and the ask.

## Message-discipline checklist
The short list the candidate reviews before walking on stage.
```

Write real answer copy in the candidate's voice, not descriptions of answers.

## Guidance

- **Prepare the hardest version.** Drill the most hostile phrasing of every
  attack. If the candidate can handle that, the real question is easy.
- **One point, not five.** A 30-second answer makes a single point and lands the
  message. Cramming loses both.
- **Every answer ends on message.** No matter the question, the last sentence
  should move toward the core message and, where natural, the ask.
- **Contrast, do not attack blindly.** Contrasts are factual and tied to an issue
  voters care about. Personal attacks usually cost more than they gain.
- **Bridge without dodging.** Acknowledge the question honestly, then pivot. A
  pivot that ignores the question reads as evasion. See the bridging guide.

## Message-discipline checklist (starting template)

Adapt per candidate:

- Know the three things to say no matter what.
- Answer the question, then bridge to one of the three.
- Shortest true answer beats the cleverest long one.
- Stay calm under attack; the room reads composure as strength.
- Land the ask in the close.
